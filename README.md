# 🍴 Zomato Late Delivery Prediction Dashboard  

An interactive **data analytics and machine learning project** that predicts whether a food order will be **Late** or **On Time**, based on real-world delivery factors such as **distance, traffic, weather, restaurant rating, and order type**.  

---

## 🚀 Project Overview  
This project aims to analyze late deliveries in Zomato orders and predict potential delays using **Business Analytics + Machine Learning** techniques.  

Through **Exploratory Data Analysis (EDA)** and visualization, key patterns were identified that influence delivery performance.  
A **Random Forest Classifier** model was built and deployed using **Streamlit** for interactive predictions.  

---

## 🧠 Features  
✅ Perform **data analysis & visualization** on delivery trends  
✅ **Predict late/on-time deliveries** based on custom input  
✅ **Interactive Streamlit Dashboard** for real-time testing  
✅ Clear and insightful **EDA charts** (Weather, Traffic, Distance, Ratings)  
✅ Easy-to-run, beginner-fr
